CYBERSECURITY LESSON

Safe Browsing 🌐

Learn how to identify suspicious websites, links, and online activities.

🌐 What is Safe Browsing?

Safe browsing means using the internet carefully and making informed decisions before opening links, downloading files, or entering sensitive information.

A website can look professional and still be fraudulent, so it is important to examine the website and the context of the request.

🔎 Check the Website Address

Before entering sensitive information, carefully examine the website address.

  • Check the spelling of the domain name.
  • Be careful with unexpected or unfamiliar domains.
  • Don't assume that a padlock icon alone means a website is trustworthy.
  • Be especially careful with links received unexpectedly through messages or email.

🚨 Signs of a Suspicious Website

  • The domain name contains unusual spelling.
  • The website creates extreme urgency or fear.
  • It unexpectedly asks for passwords or authentication codes.
  • It asks for unnecessary personal information.
  • The website contains excessive pop-ups or unexpected downloads.
  • The offer seems too good to be true.

🔗 Be Careful With Links

Don't automatically trust a link just because it appears to come from someone you know.

If you receive an unexpected message asking you to sign in, consider navigating to the organization's official website yourself instead of using the link.

📥 Safe Downloads

  • Download software from trusted sources.
  • Avoid pirated or modified software.
  • Be cautious with unexpected email attachments.
  • Keep your operating system and applications updated.

📡 Public Wi-Fi

Public networks can create additional security risks.

  • Avoid performing highly sensitive activities on untrusted networks when possible.
  • Use HTTPS websites.
  • Keep your device and applications updated.
  • Disable automatic connection to unknown networks.

⭐ Safe Browsing Rules

  1. Stop before clicking unexpected links.
  2. Check the domain carefully.
  3. Never share passwords or verification codes because someone asks for them.
  4. Download software only from trusted sources.
  5. Keep your software updated.
  6. When in doubt, verify through an independent trusted source.
